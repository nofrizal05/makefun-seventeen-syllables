An entry for make.fun's **"Seventeen Syllables of Debugging"** bounty
($5 — 1st $2 / 2nd $2 / 3rd $1).

One original haiku about debugging — three lines, exact 5-7-5 syllables,
under 200 characters. A breakpoint holds its breath, the log swears nothing
is wrong, and the bug itself has the last word.

## The haiku

> Breakpoint holds its breath
> the log swears that nothing's wrong
> the bug grins at me

## Run it

```bash
python3 main.py
```

`main.py` (Python 3.13 standard library only) writes the haiku to
`/output/entry.txt` and nothing else.
